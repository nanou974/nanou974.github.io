Politique de confidentialité – Chiffrage Fab

Dernière mise à jour : 2 novembre 2026

1. Qui est responsable

Chiffrage Fab est éditée par Gianny Blard (activité « BG3d81 »). Contact : bg3d81@gmail.com.

2. Quelles données sont traitées

Chiffrage Fab ne collecte aucune donnée personnelle sur des serveurs. Toutes les informations que vous saisissez (identité de votre entreprise, clients, devis, fiches de revient, factures, paramètres) sont enregistrées uniquement dans le navigateur ou l'application de votre appareil (stockage local).

L'application ne contient ni publicité, ni outil de mesure d'audience, ni traceur, ni compte utilisateur.

3. Avis utilisateur

Si vous envoyez un avis depuis l'application, celui-ci est transmis par votre propre messagerie (ou par Gmail, si vous choisissez ce lien). Le contenu de votre message (note, commentaire, suggestion) est alors reçu par l'éditeur à l'adresse indiquée ci-dessus. L'application ne conserve aucune trace de cet envoi.

4. Exports

Les archives PDF et ZIP sont générées sur votre appareil et téléchargées par vous. Elles ne sont envoyées à personne.

5. Hébergement

L'application est hébergée par GitHub Pages. GitHub peut enregistrer les données techniques habituelles de connexion (adresse IP, navigateur) selon sa propre politique de confidentialité.

6. Vos droits

Comme les données restent sur votre appareil, vous en gardez le contrôle : vous pouvez les supprimer en vidant le stockage du navigateur ou en désinstallant l'application. Pour toute question, écrivez à bg3d81@gmail.com.

7. Modifications

Cette politique peut être mise à jour. La date en haut de page indique la dernière version.
